## Tecnologías y Herramientas Utilizadas

Para el desarrollo de este sitio he empleado las siguientes tecnologías:

-Maquetación y Estructura: HTML5 y CSS3 enfocados en semántica y accesibilidad.
-Framework CSS: Bootstrap 5, utilizando componentes nativos como Cards, Navbar y el sistema de Grid responsive.
-Diseño e Iconografía: FontAwesome y Devicons.
-Control de Versiones y Despliegue: Git, GitHub, GitHub Pages y Vercel.


## Características del Proyecto

-Diseño Responsive: Adaptado para su correcta visualización en dispositivos móviles, tablets y ordenadores de escritorio.
-Código Limpio: Estructura basada en las clases de utilidad de Bootstrap, evitando el uso excesivo de CSS personalizado inline para facilitar el mantenimiento.
-Sección de Habilidades: Lenguajes ordenados, frameworks y bases de datos mediante un sistema de tarjetas.
-Contacto Directo: Integración de enlaces nativos de tipo mailto para permitir una comunicación rápida con una persona.
